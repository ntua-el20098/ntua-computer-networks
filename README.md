# NTUA ECE - Computer Networks - 7th Semester

## Overview

This repository contains solutions to exercises from the Computer Networks course (7th Semester, ECE NTUA).

## Topics Covered

The exercises explore various networking concepts, including:

- **Packet Analysis with Wireshark**
- **Ethernet & Address Resolution Protocol (ARP)**
- **IPv4 & Fragmentation**
- **Network Topology Discovery using traceroute and IPv4 Record Route option**
- **Internet Control Message Protocol (ICMP)**
- **User Datagram Protocol (UDP)**
- **Transmission Control Protocol (TCP)**
- **Application Layer Protocols:**
  - TELNET, FTP, TFTP
  - Simple Mail Transfer Protocol (SMTP), Dynamic Host Configuration Protocol (DHCP)
  - Domain Name System (DNS)
  - Hypertext Transfer Protocol (HTTP)
  - HTTPS, Transport Layer Security (TLS), and SSH
